# How to cite these resources

Cite the specific publication and edition that supports your work. If you rely on both resources, cite both.

## TRAIT Framework

Giardino, T. J. (2026). The Responsible AI Transition (TRAIT) Framework (Version 2.1, November 2026 Hybrid Intelligence Expansion Update). myWorkforceAgents.ai. https://myworkforceagents.ai/ai-transition-framework

The revision date printed in this edition is November 1, 2026. [Read the included edition](publications/TRAIT_Framework_November_2026_v2_1.pdf).

## Employee Guide

Giardino, T. J. (2026). Working With Digital Labor: A Practical Guide for Employees Navigating AI-Enabled Work (Version 1.2, November 2026 edition). myWorkforceAgents.ai. https://myworkforceagents.ai/employee-digital-labor-fm

The document status describes this edition as prepared for November 1, 2026 release. [Read the included edition](publications/Working_With_Digital_Labor_November_2026_v1_2.pdf).

## GitHub citation button

CITATION.cff uses the TRAIT Framework as its preferred report citation. GitHub supports one preferred citation in this field. The button does not replace the separate Employee Guide citation.

The structured citation lists the author's name without honorifics or professional credentials, as customary in bibliographic records.

## Citing the repository itself

When discussing this GitHub collection or its introductory guidance, identify Managing Hybrid Intelligence Public Resource Library, Dr. Timothy J. Giardino, the actual repository URL, and the release or commit you used. Add your access date if required by your chosen citation style.

The repository package version and the individual publication versions describe different things. Use the original publication version when citing its substantive content.

For a stable record of a specific passage, include its section or page and, where useful, a link to the file in the release or commit you consulted. The official publisher page may later offer a newer edition.
