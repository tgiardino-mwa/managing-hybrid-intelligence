## Which version should I use

Use the included PDFs when you need to refer to or examine the edition associated with this repository package. Check the official publication pages when you need the latest available edition.

A GitHub release such as version 1.0.0 identifies the repository package. It does not rename TRAIT version 2.1 or Employee Guide version 1.2.

If a future edition changes a substantive rule, cite and apply the edition you actually consulted. Do not silently combine requirements from different editions.
